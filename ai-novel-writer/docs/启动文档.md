# 墨飞小说创造 - 启动文档

## 环境要求

- Node.js 18+
- PostgreSQL 数据库
- npm / yarn / pnpm / bun

---

## 快速启动

### 1. 安装依赖

```bash
cd ai-novel-writer
npm install
```

### 2. 配置环境变量

复制配置模板并修改：

```bash
cp .env.example .env.local
```

编辑 `.env.local`，配置以下必要项：

```env
# 数据库（已配置）
DATABASE_URL="postgresql://novelist:Novelist123@122.51.186.204:5432/novelist_dev"

# NextAuth
NEXTAUTH_SECRET="mofei-novel-writer-secret-key-2026"
NEXTAUTH_URL="http://localhost:3000"

# 邮件服务（已配置）
MAIL_USERNAME="wangTest321@163.com"
MAIL_PASSWORD="WVuUuxnuBBiWqi2x"
MAIL_DEFAULT_SENDER="墨飞小说创造<wangTest321@163.com>"

# AI 模型（需要填入你的 API Key）
DEEPSEEK_API_KEY=""
```

### 3. 初始化数据库

```bash
# 生成 Prisma 客户端
npx prisma generate

# 运行数据库迁移
npx prisma migrate dev
```

### 4. 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000

## Docker 部署

```bash

docker build -t ai-novel-writer .

# 运行容器
docker run -p 3000:3000 \
  -e DATABASE_URL="postgresql://..." \
  -e NEXTAUTH_SECRET="..." \
  ai-novel-writer

# 或使用 docker-compose
docker-compose up -d
```

## 常见问题

### 1. 数据库连接失败

检查 DATABASE_URL 是否正确，确保服务器 IP 可访问。

```bash
# 测试连接
npx prisma db pull
```

### 2. 邮件发送失败

- 检查邮箱授权码是否正确
- 确认 163 邮箱已开启 SMTP 服务

### 3. AI 生成无响应

- 检查 DEEPSEEK_API_KEY 是否配置
- 查看 API Key 是否有效

| DEEPSEEK_API_KEY | DeepSeek API Key | ❌ |
| KIMI_API_KEY | Kimi API Key | ❌ |
| GLM_API_KEY | 智谱 API Key | ❌ |
