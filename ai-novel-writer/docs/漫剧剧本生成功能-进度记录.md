## 十、Toonflow-app 对比分析（2026-03-15）

### 10.1 架构对比

| 维度 | Toonflow-app | 本设计 |
|------|--------------|--------|
| 提示词存储 | 数据库 (t_prompts) | 代码文件 |
| 多代理协作 | ✅ AI1/AI2/director | ❌ 单一提示词 |
| 工具调用 | ✅ 丰富工具集 | ❌ 纯文本生成 |
| 图片生成 | ✅ 集成 generateImageTool | ❌ P2 功能 |
| 动态可配置 | ✅ 运行时可修改 | ❌ 需要发版 |
| SSE 流式 | ❌ | ✅ |
| 独立会员 | ❌ | ✅ |
| 低成本 | ❌ | ✅ DeepSeek |

### 10.2 Toonflow-app 亮点（可借鉴）

1. **多代理协作机制**
   - AI1 (storyline) → 生成故事线
   - AI2 (outline) → 生成详细大纲
   - director → 审核并修正

2. **分镜两阶段处理**
   - segmentAgent → 拆分片段（情感、动作）
   - shotAgent → 生成具体镜头（含图片提示词）

3. **丰富的结构化输出**
   - openingHook, endingHook (钩子设计)
   - emotionalCurve (情感曲线)
   - visualHighlights (视觉高光)
   - classicQuotes (经典台词)

### 10.3 许可证风险

⚠️ **AGPL-3.0 限制**：
- 商业使用需开源整个应用
- 网络服务使用也触发开源义务
- 不能直接复用代码、提示词、数据结构

✅ **可借鉴（不涉及版权）**：
- 功能流程设计思路
- 用户交互模式
- 多代理架构理念

### 12.2 待设计：AI 漫剧生成功能

> 📋 状态：待设计
> 📅 预计设计时间：2026-03-16

- 入口：剧本（支持从剧本系统导入，也支持独立创建）

- 独立：与小说、剧本系统解耦，可单独使用

**参考项目**：
- [ ] Toonflow-app (AGPL-3.0) - 架构思路参考
- [ ] 其他开源漫剧/短剧生成项目 - 待调研

**待设计内容**：
- [ ] 功能需求分析
- [ ] 数据模型设计
- [ ] 图片生成 API 选型（SiliconFlow / Midjourney / 可灵AI）

- [ ] 提示词设计（图片风格、角色一致性）

1. 角色一致性：多镜头同一角色外观保持一致
