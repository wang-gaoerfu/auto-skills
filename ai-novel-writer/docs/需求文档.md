# AI小说创作能手 - 需求文档

## 项目概述

### 项目目标
开发一个基于Web的AI小说创作平台，提供智能化的小说生成、编辑、优化功能，并支持用户注册登录和会员机制（不含支付功能，采用兑码激活方式）。

### 参考项目
- **项目名称**：AI-automatically-generates-novels
- **GitHub地址**：https://github.com/wfcz10086/AI-automatically-generates-novels
- **核心理念**：基于AI+提示词的智能小说创作生产力工具

### AI模型选型
**主要采用国内大模型**（成本低、性能优秀）：
- **DeepSeek V3**：主力模型，性价比极高（¥0.1/万tokens）
- **Kimi（月之暗面）**：长文本处理能力强（200万字）
- **阿里千问（通义千问）**：稳定可靠，创作能力好
- **智谱清言（GLM-4-Flash）**：完全免费，适合免费用户
