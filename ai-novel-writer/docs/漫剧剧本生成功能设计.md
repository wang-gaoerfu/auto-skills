## 一、功能概述

### 1.1 功能定位

为 AI 小说创作能手平台新增**漫剧剧本生成**模块，支持将小说内容（自有/外部）转换为专业的分镜剧本格式，用于后续 AI 漫剧/短剧制作。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| **内容变现** | 小说作者可将作品转化为漫剧剧本，拓展变现渠道 |
| **降低门槛** | 无需专业编剧知识，AI 自动生成分镜脚本 |
| **解耦设计** | 剧本系统独立于小说系统，互不影响 |
| **多来源支持** | 支持自有项目、外部小说、从零创作 |

### 1.3 与现有系统的关系

```
┌─────────────────────────────────────────────────────────────┐
│                    AI 小说创作能手                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────┐         ┌─────────────────┐           │
│  │   小说系统       │   →→→   │   剧本系统       │           │
│  │  (现有功能)      │  导入   │  (新增功能)      │           │
│  │                 │         │                 │           │
│  │  - 项目管理      │         │  - 剧本项目管理  │           │
│  │  - 章节编辑      │         │  - 场景/镜头管理  │           │
│  │  - 知识库        │         │  - AI 分镜生成   │           │
│  │  - AI 生成       │         │  - 多格式导出    │           │
│  └─────────────────┘         └─────────────────┘           │
│         ↑                           ↑                       │
│         │                           │                       │
│    用户原创小说              外部小说导入                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘

关键设计原则：两个系统完全解耦，数据独立存储，互不影响
```

## 二、需求分析

### 2.1 用户故事

| 角色 | 需求 | 价值 |
|------|------|------|
| 小说作者 | 我想把我的小说转成漫剧剧本 | 拓展作品形式，增加收入 |
| 短剧创作者 | 我想导入别人的小说生成剧本 | 快速获取素材，提高效率 |
| 内容运营 | 我想批量生成剧本用于制作 | 降低内容生产成本 |
| 编剧新手 | 我想学习专业剧本格式 | AI 生成的规范格式可作为参考 |

### 2.2 功能需求清单

#### 2.2.1 剧本项目管理（P0）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建剧本项目 | 新建空白剧本项目 | P0 |
| 项目基本信息 | 标题、简介、封面、类型标签 | P0 |
| 项目列表 | 查看所有剧本项目 | P0 |
| 项目删除 | 删除剧本项目及关联数据 | P0 |
| 项目搜索 | 按标题/标签搜索 | P1 |

#### 2.2.2 内容导入（P0）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 从我的项目导入 | 选择已有小说项目，复制内容 | P0 |
| 上传 TXT 文件 | 上传外部小说 TXT 文件 | P0 |
| 复制粘贴文本 | 直接粘贴小说文本 | P0 |
| AI 智能分章 | 自动识别章节边界并分割 | P0 |
| AI 要素提取 | 提取角色、场景、剧情线 | P0 |

#### 2.2.3 剧本生成（P0）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 章节转分镜 | 选择章节，AI 生成分镜剧本 | P0 |
| 批量生成 | 一次性生成多个章节的分镜 | P0 |
| 流式生成 | 实时展示生成进度 | P0 |
| 生成参数配置 | 镜头密度、对白风格等 | P1 |

#### 2.2.4 剧本编辑（P0）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 手动编辑 | 直接修改生成的剧本内容 | P0 |
| AI 辅助修改 | 选中文本，AI 润色/扩写/调整 | P0 |
| 分段重新生成 | 针对某个场景/镜头单独重新生成 | P0 |
| 场景排序 | 拖拽调整场景顺序 | P1 |
| 镜头排序 | 场景内镜头顺序调整 | P1 |

#### 2.2.5 导出功能（P1）

| 格式 | 用途 | 优先级 |
|------|------|--------|
| JSON | 对接 AI 生图/视频工具 | P0 |
| Markdown | 人工审阅、分享 | P0 |
| PDF | 打印、正式交付 | P1 |
| Excel/CSV | 导入剪辑软件、项目管理 | P1 |

### 2.3 非功能需求

| 需求 | 描述 |
|------|------|
| 性能 | 单章节分镜生成 < 30 秒 |
| 可用性 | 界面简洁，操作直观 |
| 兼容性 | 支持主流浏览器 |
| 成本控制 | 使用 DeepSeek 等低成本模型 |

## 三、剧本格式设计

### 3.1 分镜剧本格式规范

```yaml
# 剧本元数据
meta:
  title: "剧本标题"
  source: "来源小说名称"
  genre: "都市爱情"          # 题材类型
  totalScenes: 12           # 场景总数
  estimatedDuration: "5分钟" # 预估时长
  characters:               # 角色列表
    - id: "char_001"
      name: "小雨"
      description: "25岁女性，黑色长发，白色连衣裙"
    - id: "char_002"
      name: "林远"
      description: "28岁男性，短发，西装"

# 场景列表
scenes:
  - id: "scene_001"
    sceneNumber: 1
    title: "咖啡馆门口"
    timeOfDay: "日"          # 日/夜/黄昏/黎明
    location: "外"           # 内/外
    description: "繁华街道边的咖啡馆门口，人来人往"
    mood: "期待、紧张"       # 场景氛围
    shots:                   # 镜头列表
      - id: "shot_001_001"
        shotNumber: "1-1"
        shotType: "中景"     # 特写/近景/中景/全景/远景
        angle: "平视"        # 平视/仰视/俯视/斜角
        duration: 3          # 预估秒数

        # 画面描述（用于 AI 生图）
        visual:
          subject: "小雨站在咖啡馆门口"
          characters:
            - characterId: "char_001"
              action: "来回踱步"
              expression: "紧张、期待"
              position: "画面中央"
          environment: "咖啡馆门口，街道背景，行人模糊"
          lighting: "自然光，阳光明媚"
          colorTone: "温暖色调"

        # 音频描述
        audio:
          dialogue:
            - character: "小雨（内心）"
              line: "他会不会来..."
              type: "旁白"    # 对白/旁白/内心独白
          soundEffects:
            - "街道嘈杂声"
            - "手机震动声"
          backgroundMusic: "轻柔的钢琴曲"

        # 镜头运动
        camera:
          movement: "固定"    # 固定/推/拉/摇/移/跟
          transition: "切"    # 切/淡入/淡出/叠化

      - id: "shot_001_002"
        shotNumber: "1-2"
        shotType: "特写"
        visual:
          subject: "手机屏幕"
          environment: "显示来电：林远"
        audio:
          soundEffects:
            - "手机震动声"
        duration: 2

  - id: "scene_002"
    sceneNumber: 2
    title: "咖啡馆内"
    # ... 更多场景
```

### 3.2 镜头类型对照表

| 镜头类型 | 英文 | 用途 | AI 生图提示 |
|---------|------|------|------------|
| 特写 | Close-up | 表情、细节 | close-up shot, face details |
| 近景 | Close Shot | 胸以上 | close shot, upper body |
| 中景 | Medium Shot | 腰以上 | medium shot, waist up |
| 全景 | Full Shot | 全身 | full body shot |
| 远景 | Long Shot | 环境 | wide shot, environment |
| 过肩 | Over Shoulder | 对话 | over the shoulder shot |
| 主观 | POV | 角色视角 | point of view shot |

### 3.3 导出格式示例

#### JSON 格式（对接 AI 工具）

```json
{
  "meta": { ... },
  "scenes": [ ... ],
  "exportConfig": {
    "imageProvider": "midjourney",
    "videoProvider": "runway",
    "aspectRatio": "9:16"
  }
}
```

#### Markdown 格式（人工审阅）

```markdown
# 《遇见》漫剧剧本

## 场景 1：咖啡馆门口（日/外）

### 镜头 1-1 【中景】
```

### 4.2 Prisma Schema 新增

```prisma
// ============================================
// 剧本项目模型
// ============================================
model ScriptProject {
  id              String    @id @default(cuid())
  userId          String
  title           String
  description     String?
  coverImage      String?
  sourceType      String    @default("ORIGINAL") // OWN_PROJECT, EXTERNAL, ORIGINAL
  sourceProjectId String?   // 如果来自自有小说项目
  genre           String?
  status          String    @default("draft") // draft, generating, completed
  settings        Json?     // 生成配置
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt

  user            User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  sourceProject   Project?  @relation(fields: [sourceProjectId], references: [id], onDelete: SetNull)
  sources         ScriptSource[]
  characters      ScriptCharacter[]
  scenes          ScriptScene[]

  @@index([userId])
  @@index([status])
  @@map("script_projects")
}

// ============================================
// 剧本原始素材模型
// ============================================
model ScriptSource {
  id              String    @id @default(cuid())
  scriptProjectId String
  chapterTitle    String
  content         String    @db.Text
  order           Int
  createdAt       DateTime  @default(now())

  scriptProject   ScriptProject @relation(fields: [scriptProjectId], references: [id], onDelete: Cascade)

  @@index([scriptProjectId])
  @@index([order])
  @@map("script_sources")
}

// ============================================
// 剧本角色模型
// ============================================
model ScriptCharacter {
  id              String    @id @default(cuid())
  scriptProjectId String
  name            String
  description     String?
  appearance      Json?     // 外观描述：发型、服装、特征等
  personality     String?
  vectorId        String?   // 向量检索用
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt

  scriptProject   ScriptProject @relation(fields: [scriptProjectId], references: [id], onDelete: Cascade)

  @@index([scriptProjectId])
  @@map("script_characters")
}

// ============================================
// 剧本场景模型
// ============================================
model ScriptScene {
  id              String    @id @default(cuid())
  scriptProjectId String
  sourceId        String?   // 关联原始素材
  sceneNumber     Int
  title           String
  timeOfDay       String?   // 日/夜/黄昏/黎明
  location        String?   // 内/外
  description     String?   @db.Text
  mood            String?   // 场景氛围
  order           Int
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt

  scriptProject   ScriptProject @relation(fields: [scriptProjectId], references: [id], onDelete: Cascade)
  source          ScriptSource? @relation(fields: [sourceId], references: [id], onDelete: SetNull)
  shots           ScriptShot[]

  @@index([scriptProjectId])
  @@index([order])
  @@map("script_scenes")
}

// ============================================
// 剧本镜头模型
// ============================================
model ScriptShot {
  id              String    @id @default(cuid())
  sceneId         String
  shotNumber      String    // "1-1", "1-2" 等
  shotType        String    // 特写/近景/中景/全景/远景
  angle           String?   // 平视/仰视/俯视/斜角
  visual          Json?     // 画面描述
  audio           Json?     // 音频描述
  camera          Json?     // 镜头运动
  duration        Int       @default(3) // 秒数
  order           Int
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt

  scene           ScriptScene @relation(fields: [sceneId], references: [id], onDelete: Cascade)

  @@index([sceneId])
  @@index([order])
  @@map("script_shots")
}
```

```typescript
   - 示例："你一个被嘲笑异想天开的学生，却让投资人主动送上门"
5. **金句型**：深刻洞察、情感共鸣、价值观表达
```

#### 8.2.1 流式生成实现

```typescript
// /api/scripts/[id]/generate/route.ts
export async function POST(request: Request) {
  const encoder = new TextEncoder()

  const stream = new ReadableStream({
    async start(controller) {
      // 1. 获取章节内容
      const sources = await getScriptSources(scriptProjectId)

      // 2. 逐章生成
      for (const source of sources) {
        // 发送开始信号
        controller.enqueue(encoder.encode(`data: ${JSON.stringify({
          type: 'start',
          chapterOrder: source.order,
          chapterTitle: source.chapterTitle
        })}\n\n`))

        // AI 生成（流式）
        for await (const chunk of generateScriptStream(source.content, characters, scenes)) {
          controller.enqueue(encoder.encode(`data: ${JSON.stringify({
            type: 'chunk',
            content: chunk.content
          })}\n\n`))
        }

        // 发送完成信号
        controller.enqueue(encoder.encode(`data: ${JSON.stringify({
          type: 'complete',
          chapterOrder: source.order
        })}\n\n`))
      }

      controller.close()
    }
  })

  return new Response(stream, {
    headers: { 'Content-Type': 'text/event-stream' }
  })
}
```

```typescript
async function processLargeText(text: string) {
  const CHUNK_SIZE = 10000 // 每块 10000 字符

  if (text.length <= CHUNK_SIZE) {
    return await analyzeWithAI(text)
  }

  // 分块分析后合并
  const chunks = splitIntoChunks(text, CHUNK_SIZE)
  const results = await Promise.all(
    chunks.map(chunk => analyzeWithAI(chunk))
  )

  return mergeResults(results)
}
```
