### 认证流程

```
注册流程:
1. 用户输入邮箱 → 发送验证码
2. 用户输入验证码、密码、昵称
3. 验证码验证通过 → 创建用户 → 创建 FREE 会员 → 发送欢迎邮件
4. 自动登录 → 跳转仪表盘

登录流程:
1. 用户输入邮箱、密码
2. 验证用户 → 验证密码 → 生成 JWT
3. 跳转仪表盘
```

- `/projects` - 项目管理
- `/knowledge` - 知识库
- `/settings` - 设置
- `/admin/*` - 管理后台（仅管理员）
