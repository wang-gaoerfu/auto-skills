## 🔥 核心功能详解

### 1. 一键自动创作 ✅

**路径**: `/projects/new`

**功能流程**:
1. 选择小说题材和长度
2. AI 生成推荐标题和简介
3. 点击「一键创作」自动完成：
   - 创建项目
   - 生成知识库（人物、世界观、剧情、场景、对话）
   - 批量生成所有章节
   - 自动标记完结
4. 支持任务取消和断点续传
5. 显示 Token 消耗统计

**API**: `POST /api/projects/auto-create`

```typescript
// 流式响应
{
  type: "progress",
  stage: "creating_project" | "generating_knowledge" | "generating_chapters" | "completing",
  message: "正在生成章节...",
  progress: { current: 3, total: 5 }
}
```

### 2. 批量生成章节 ✅

**路径**: 项目详情页

**功能**:
- 自动模式：根据小说长度自动计算章节数
- 人工模式：指定目标章节数或新增章节数
- 完结模式：自动生成结局章节
- 流式进度显示
- 章节标题格式：`【第X章】` / `【第X章】 大结局`

**API**: `POST /api/projects/[id]/batch-generate`

### 3. 完结检测 ✅

**功能**:
- 字数检测：是否达到目标字数
- 章节数检测：是否达到目标章节
- 结局信号检测：
  - 结局关键词检测（大结局、全书完等）
  - 冲突是否解决（AI分析）
- 智能建议生成
- 一键创建补充章节

**API**: `POST /api/projects/[id]/complete`

**强结局关键词**:
```typescript
const strongEndingKeywords = ["大结局", "全书完", "剧终", "终章", "完结篇", "落幕"]
```

### 4. 知识库管理 ✅

**类型**:
| 类型 | 说明 |
|------|------|
| character | 人物设定 |
| world | 世界观 |
| plot | 剧情设定 |
| scene | 场景素材 |
| dialogue | 对话模板 |

**功能**:
- 手动创建/编辑
- AI 一键生成
- 标签管理
- 项目关联

### 5. 阅读模式 ✅

**路径**: `/projects/[id]/read`

**功能**:
- 章节目录导航
- 阅读进度保存
- 字体大小调节
- 行间距调节
- 阅读区域深色模式（独立于全局主题）
- 键盘快捷键（左右箭头翻页）

### 6. 主题切换 ✅

**功能**:
- 全站明暗主题切换
- 所有页面都有主题切换按钮
- 偏好保存到 localStorage
- 系统主题跟随

**涉及文件**:
- `src/components/theme-toggle.tsx`
- `src/components/theme-provider.tsx`
- `src/components/layout/user-nav.tsx`
- 所有页面 header 组件

### 7. 章节标题编辑 ✅

**功能**:
- 在章节编辑页点击标题旁的铅笔图标
- 输入新标题
- Enter 保存，Escape 取消
- 自动保存到数据库

## 🗄️ 数据库模型

### Prisma Schema

```prisma
model User {
  id            String    @id @default(cuid())
  email         String    @unique
  password      String
  name          String?
  role          String    @default("USER")  // USER, ADMIN
  isActive      Boolean   @default(true)
  membership    Membership?
  projects      Project[]
  knowledge     KnowledgeEntry[]
  usageLogs     UsageLog[]
  autoCreateTasks AutoCreateTask[]
}

model Membership {
  id              String    @id @default(cuid())
  userId          String    @unique
  plan            String    @default("FREE")  // FREE, VIP, PRO
  status          String    @default("APPROVED")
  expiresAt       DateTime?
  redemptionCodeId String?
  // ...
}

model Project {
  id            String    @id @default(cuid())
  userId        String
  title         String
  description   String?
  genre         String?
  novelLength   String?   // micro, short, medium, long
  status        String    @default("draft")  // draft, writing, completed
  targetWords   Int?
  targetChapters Int?
  completedAt   DateTime?
  chapters      Chapter[]
  knowledge     KnowledgeEntry[]
  autoCreateTasks AutoCreateTask[]
}

model Chapter {
  id            String    @id @default(cuid())
  projectId     String
  title         String
  content       String    @default("")
  order         Int
  wordCount     Int       @default(0)
  vectorId      String?
}

model KnowledgeEntry {
  id            String    @id @default(cuid())
  userId        String
  projectId     String?
  entryType     String    // character, world, plot, scene, dialogue
  title         String
  content       Json
  tags          String[]
  vectorId      String?
}

model AutoCreateTask {
  id              String    @id @default(cuid())
  userId          String
  projectId       String
  status          String    @default("pending")  // pending, running, paused, completed, failed, cancelled
  currentStage    String    @default("")
  progress        Json      @default("{}")
  title           String
  genre           String
  novelLength     String
  targetChapters  Int       @default(3)
  generatedChapters Int     @default(0)
  totalWordCount    Int     @default(0)
  tokensUsed        Int     @default(0)
  errorMessage      String?
  // timestamps...
}
```
