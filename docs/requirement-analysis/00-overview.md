# 需求分析系统 - 概述

## 系统介绍

Auto-Skills 需求分析系统是一套专门用于软件需求分析的技能集合，帮助您将模糊的想法转化为结构化的需求文档。

---

## 核心理念

> "从想法到文档，从对话到结构"

需求分析是一个渐进式的对话过程，而不是一次性的文档编写。我们的系统支持：

1. **对话式澄清** - 通过智能对话逐步明确需求
2. **结构化整理** - 将零散信息整理为标准格式
3. **文档自动生成** - 一键生成专业的需求文档

---

## 技能组成

### req-clarify（需求澄清）

**用途**: 通过对话收集和分析软件需求

**核心职责**:
- 系统性追问需求要素
- 输出 9 要素需求框架
- 提供专业建议

**输出**: 结构化需求要素（9 要素）

---

### req-structure（需求结构化）

**用途**: 将需求整理为标准文档结构

**核心职责**:
- 支持 4 种文档模板
- 生成符合规范的 SRS 结构
- 可选的 Mermaid 图表

**输出**: 标准文档结构（Markdown 格式）

---

### doc-generator（文档生成器）

**用途**: 生成最终的 Markdown 文档文件

**核心职责**:
- 写入文件到指定路径
- 支持目录和元信息
- 可选的图表包含

**输出**: 完整的 .md 文件

---

## 完整工作流

```
┌─────────────┐
│  原始需求   │
│ (模糊想法)  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│req-clarify  │ ◄── 对话澄清
│ 需求澄清    │
└──────┬──────┘
       │
       ▼ 9 要素结构
┌─────────────┐
│req-structure│ ◄── 结构整理
│ 需求结构化  │
└──────┬──────┘
       │
       ▼ 文档结构
┌─────────────┐
│doc-generator│ ◄── 文件生成
│ 文档生成    │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  需求文档   │
│  (.md文件)  │
└─────────────┘
```

## 与 task-clarify 的区别

| 特性 | task-clarify | req-clarify |
|------|-------------|-------------|
| **用途** | 任务拆解 | 需求分析 |
| **适用场景** | 已有明确需求，需要拆解任务 | 需求不明确，需要澄清 |
| **输出** | 6 要素任务清单 | 9 要素需求框架 |
| **追问重点** | 任务目标、验收标准 | 业务背景、用户场景、技术约束 |
| **输出格式** | 任务清单 | 完整需求文档 |

**使用建议**:
- 需求不明确时 → 先用 `/req-clarify`
- 需求已明确，需要拆解任务 → 用 `/task-clarify`

## 快速开始

### 最简单的使用方式

```bash
# 1. 需求澄清
/req-clarify

# 2. 需求结构化
/req-structure

# 3. 文档生成
/doc-generator
```

### 指定项目类型

```bash
# Web 应用项目
/req-clarify project-type:web

# API 项目
/req-clarify project-type:api
```

### 完整流程示例

```
用户: 我想做一个电商网站

AI: 让我了解一下具体需求...
     [系统追问]

用户: [回答问题...]

AI: [输出 9 要素需求]

用户: /req-structure

AI: [输出 SRS 文档结构]

用户: /doc-generator output-path:docs/requirements/ecommerce.md

AI: ✓ 文档生成成功
     文件路径: docs/requirements/ecommerce.md
```
