# skill-manager 软件需求规格说明书

## 1. 项目概述

### 1.1 需求背景

随着本地 skills 数量逐渐增多，开发者面临以下问题：

- **记忆负担**：难以记住所有可用的技能
- **查找困难**：完成需求时，需要手动查找和判断应该使用哪些技能
- **创建繁琐**：创建新技能需要手动复制模板、修改多个文件
- **管理不便**：修改或删除既有技能需要定位多个文件

### 1.2 项目目标

开发一个技能管理助手 (skill-manager)，提供：

1. 统一的技能查看和管理入口
2. AI 智能匹配，自动推荐适合当前任务的技能
3. 简化新技能创建和既有技能修改的流程

### 1.3 目标用户

- **主要用户**：Auto-Skills 项目的维护者和贡献者
- **次要用户**：使用自定义技能的 Claude Code 用户

## 2. 功能需求

### 2.1 核心功能 (P0)

#### 2.1.1 列出所有技能 (list)

展示本地所有 skills 的关键信息：

| 字段 | 说明 |
|------|------|
| 名称 | skill 目录名 |
| 显示名称 | displayName |
| 描述 | description |
| 版本 | version |
| 路径 | 相对路径 |

**命令格式**：`/skill-manager list`

**输出示例**：
```
✓ 找到 6 个技能

| 名称 | 显示名称 | 描述 | 版本 | 路径 |
|------|----------|------|------|------|
| file-ops | File Operations Helper | 文件操作助手... | 1.0.0 | builtin/ |
| git-helper | Git Operations Helper | Git 操作助手... | 1.0.0 | builtin/ |
| ...
```

#### 2.1.2 智能推荐技能 (recommend)

根据用户描述的需求，AI 自动推荐相关技能。

**命令格式**：`/skill-manager recommend "<需求描述>"`

**推荐逻辑**：
1. 分析用户需求描述中的关键词
2. 匹配技能的 displayName、description、SKILL.md 内容
3. 返回最相关的 1-3 个技能
4. 说明推荐理由

**输出示例**：
```
✓ 推荐技能

根据你的需求"管理 git 提交"，推荐以下技能：

1. git-helper
   理由: 专门用于 Git 操作，支持提交、分支等功能

2. file-ops
   理由: 可能需要编辑相关文件
```

#### 2.1.3 删除技能 (delete)

删除指定的技能目录。

**命令格式**：`/skill-manager delete <skill-name>`

**安全机制**：
- 删除前显示技能详细信息
- 要求用户确认
- 不允许删除 templates 目录下的模板
- 不允许修改 community 目录（只读）

**输出示例**：
```
⚠️ 即将删除技能

技能名称: old-skill
描述: 这是一个过时的技能
路径: builtin/old-skill/
文件数: 3

确认删除? (yes/no):
```

### 2.2 重要功能 (P1)

#### 2.2.1 创建新技能 (create)

基于 basic-skill 模板，交互式创建新技能。

**命令格式**：`/skill-manager create <new-skill-name>`

**创建流程**：
1. 验证技能名称（kebab-case 格式）
2. 检查是否已存在同名技能
3. 复制 basic-skill 模板
4. 交互式引导填写：
   - displayName
   - description
   - author
   - parameters (可选)
5. 生成 SKILL.md 和 description.md

**输出示例**：
```
✓ 创建技能模板

正在创建技能: my-skill

请输入以下信息：
1. 显示名称 (My Skill): [用户输入]
2. 描述 (简短描述功能): [用户输入]
3. 作者 (Your Name): [用户输入]

✓ 技能创建成功

路径: builtin/my-skill/
文件:
  - skill.json
  - SKILL.md
  - description.md

下一步：编辑 SKILL.md 定义技能行为
```

#### 2.2.2 编辑技能 (edit)

编辑技能的指定文件。

**命令格式**：`/skill-manager edit <skill-name> file:<file-name>`

**支持的文件**：
- `skill.json` - 技能配置
- `SKILL.md` - 核心提示词
- `description.md` - 使用说明

**编辑模式**：
1. 读取当前文件内容
2. 询问用户要修改的内容
3. 使用 Edit 工具进行修改

### 2.3 未来功能 (P2)

1. 技能分类/标签管理
2. 技能启用/禁用（软删除）
3. 技能导入/导出
4. 技能依赖关系分析
5. 技能搜索（关键词模糊搜索）

### 2.4 功能边界

**明确不做**：
- 不涉及技能的执行逻辑（执行由 Claude Code 负责）
- 不管理 community 目录（只读访问）
- 不进行技能的版本控制（git 操作由 git-helper 负责）

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 目标值 |
|------|--------|
| 列出技能响应时间 | < 1 秒 |
| 支持技能数量 | 50+ |
| 推荐响应时间 | < 2 秒 |

### 3.2 安全要求

- 删除操作必须有确认机制，防止误删
- 创建/修改前验证 skill.json 格式正确性
- 不允许删除 templates 目录

### 3.3 可用性要求

- 操作失败时给出清晰的错误提示
- 支持 dry-run 模式预览操作
- 输出格式简洁清晰
