# Task Clarify - 任务澄清与拆解

## 概述

`task-clarify` 是一个需求澄清与任务拆解助手，专门帮助用户将模糊的想法转化为清晰、可执行的任务清单。

---

## 核心价值

当你只有一句话需求或模糊想法时，此技能会：
- 追问关键信息，确保理解准确
- 明确任务边界（做什么、不做什么）
- 拆解为可执行的具体任务
- 识别风险并提供应对建议

---

## 快速开始

### 基本用法

```
/task-clarify
```

然后描述你的需求，例如：
```
我想要做一个用户登录功能
```

### 跳过追问

```
/task-clarify skip-questions:true
```

直接基于现有信息输出，适合信息较完整的情况。

---

## 参数详解

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `skip-questions` | boolean | 否 | false | 是否跳过追问环节 |
| `detail-level` | string | 否 | normal | 输出详细程度：brief/normal/detailed |

---

## 使用示例

### 示例 1：模糊需求澄清

```
/task-clarify

用户输入: 帮我做个博客网站
```

**输出**：技能会追问目标、约束、验收标准等信息，然后输出完整的任务拆解。

### 示例 2：已知信息较完整

```
/task-clarify skip-questions:true

用户输入: 帮我做个博客网站，用 Next.js，两周内完成 MVP
```

**输出**：跳过追问，直接基于现有信息输出任务清单。

---

## 输出结构

技能输出包含 6 个必需部分：

### 1) 目标
一句话清晰定义任务目标

### 2) 范围
明确【要做】和【不做】的边界

### 3) 约束与假设
列出硬性约束和合理假设（最多5条）

### 4) 验收标准
可测试、可检查的完成标准

### 5) 风险清单
潜在风险及应对措施（最多5条）

### 6) 下一步任务列表
按优先级排序的可执行任务

---

## 典型输出示例

```
✓ 任务澄清完成

=== 1) 目标 ===
目标: 为 开发者 构建 个人博客系统，解决 内容分享 问题

=== 2) 范围 ===
【要做】
- 文章发布与编辑
- Markdown 支持
- 代码高亮
- 响应式设计

【不做】
- 用户注册登录
- 评论系统
- SEO 优化

=== 3) 约束与假设 ===
约束:
- 必须使用 Next.js
- 两周内完成 MVP

假设:
- 部署在 Vercel
- 使用 MDX 作为内容格式

=== 4) 验收标准 ===
- [ ] 能发布新文章
- [ ] Markdown 正确渲染
- [ ] 代码块语法高亮
- [ ] 移动端显示正常

=== 5) 风险清单 ===
1. 两周时间可能紧张 → 先砍掉非核心功能
2. MDX 配置可能复杂 → 预留 1 天调研时间

=== 6) 下一步任务列表 ===
优先级 | 任务描述 | 预估难度 | 依赖
-------|----------|----------|------
P0     | 初始化 Next.js 项目 | 低 | -
P0     | 设计文章数据结构 | 中 | -
P1     | 实现文章列表页 | 中 | 数据结构
P1     | 实现 Markdown 渲染 | 高 | -
P2     | 添加代码高亮 | 中 | Markdown 渲染
P2     | 响应式适配 | 中 | -
```

---

## 注意事项

1. **信息质量影响输出质量**：提供的信息越具体，输出越准确
2. **迭代使用**：对于复杂项目，可以多次使用此技能逐步细化
3. **保持开放心态**：技能可能提出你没考虑到的问题
