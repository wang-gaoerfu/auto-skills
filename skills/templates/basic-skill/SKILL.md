## 工具使用指南

### Read 工具

用于读取文件内容：

```
优先使用 Read 工具而非 Bash cat 命令
```

### Write 工具

用于创建或覆盖文件：

```
注意：Write 会覆盖现有文件
```

### Edit 工具

用于编辑文件的特定部分：

```
需要先使用 Read 工具读取文件
```

### Glob 工具

用于搜索文件：

```
支持通配符，如 **/*.ts
```

### Grep 工具

用于搜索文件内容：

```
支持正则表达式
```

### Bash 工具

用于执行系统命令：

```
优先使用专用工具，Bash 仅用于没有专用工具的场景
```

---

## 最佳实践

1. **优先使用专用工具**：
   - 文件操作：Read、Write、Edit
   - 搜索：Glob、Grep
   - 仅在必要时使用 Bash

2. **清晰的输出**：
   - 使用图标区分状态（✓、✗、⚠️）
   - 使用表格展示列表数据
   - 提供统计信息

3. **错误处理**：
   - 捕获并友好提示错误
   - 提供可行的解决建议
   - 避免技术术语堆砌

4. **用户确认**：
   - 危险操作前提醒用户
   - 提供 dryRun 预演选项
   - 确认后再执行

## 调试技巧

如果技能执行不正常：

1. 检查参数是否正确传递
2. 使用 {{if verbose}} 显示调试信息
3. 在每个关键步骤后输出状态
4. 检查工具调用的返回结果
