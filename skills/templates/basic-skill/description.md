## 快速开始

### 基本用法

```
/my-skill mode:fast
```

### 带参数的用法

```
/my-skill mode:detailed target:src/
```

---

## 参数详解

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `mode` | string | 是 | - | 操作模式：fast/detailed/auto |
| `target` | string | 否 | - | 目标文件或路径 |
| `verbose` | boolean | 否 | false | 是否显示详细输出 |
| `count` | number | 否 | 10 | 处理数量 |

## 使用示例

### 示例 1：快速处理

```
/my-skill mode:fast
```

说明：使用快速模式处理...

### 示例 2：详细分析

```
/my-skill mode:detailed target:src/ verbose:true
```

说明：对 src/ 目录进行详细分析，并显示详细信息

### 示例 3：自动模式

```
/my-skill mode:auto
```

说明：自动选择最佳处理方式
