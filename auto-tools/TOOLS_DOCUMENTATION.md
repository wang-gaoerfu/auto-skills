# Auto-Tools 工具说明文档

本文档详细介绍了 Auto-Tools 平台提供的所有工具及其使用方法。

---

## 文本处理工具

### 1. 字数统计 (Word Count)

**功能描述：**
全面分析文本内容，提供15+种统计指标。

**统计指标：**
- 总字符数（含/不含空格）
- 中文字符数
- 英文字符数
- 数字字符数
- 标点符号数
- 单词数
- 行数
- 段落数
- 句子数
- 平均词长
- 平均行字符数
- 预估阅读时间
- 预估朗读时间

**使用方法：**
1. 在输入框中输入或粘贴文本
2. 点击"统计"按钮
3. 查看详细的统计结果

**应用场景：**
- 文章写作统计
- 论文字数检查
- 翻译工作量评估
- 内容编辑分析

---

### 2. 大小写转换 (Case Convert)

**功能描述：**
提供10种文本大小写转换模式。

**转换模式：**
| 模式 | 说明 | 示例 |
|------|------|------|
| 全部大写 | 所有字母转为大写 | hello → HELLO |
| 全部小写 | 所有字母转为小写 | HELLO → hello |
| 首字母大写 | 每个单词首字母大写 | hello world → Hello World |
| 句首大写 | 每句话首字母大写 | hello. world → Hello. World |
| 驼峰命名 | 编程用驼峰命名 | hello world → helloWorld |
| 帕斯卡命名 | 编程用帕斯卡命名 | hello world → HelloWorld |
| 蛇形命名 | 编程用蛇形命名 | hello world → hello_world |
| 短横线命名 | 编程用短横线命名 | hello world → hello-world |
| 反转大小写 | 大小写互换 | Hello → hELLO |
| 随机大小写 | 随机转换大小写 | hello → HeLLo |

**使用方法：**
1. 输入要转换的文本
2. 选择转换模式
3. 点击"转换"按钮

**应用场景：**
- 代码命名规范转换
- 文本格式统一
- 编程变量重命名

---

### 3. 文本去重 (Text Deduplicate)

**功能描述：**
提供4种去重模式，可保留原文顺序。

**去重模式：**
| 模式 | 说明 |
|------|------|
| 行去重 | 按行去重，保留首次出现的行 |
| 词去重 | 按空格分词后去重 |
| 字符去重 | 去除重复字符 |
| 连续去重 | 去除连续重复的内容 |

**选项：**
- 区分大小写：开启时 "Hello" 和 "hello" 会被视为不同内容

**使用方法：**
1. 输入要处理的文本
2. 选择去重模式
3. 可选：开启/关闭"区分大小写"
4. 点击"去重"按钮

**应用场景：**
- 数据清洗
- 日志文件去重
- 列表整理
- 关键词去重

---

### 4. 文本排序 (Text Sort)

**功能描述：**
提供7种文本行排序方式。

**排序模式：**
| 模式 | 说明 |
|------|------|
| 升序排列 | A-Z 排序 |
| 降序排列 | Z-A 排序 |
| 按长度升序 | 短行在前 |
| 按长度降序 | 长行在前 |
| 自然排序 | 智能识别数字（如：file2.txt 在 file10.txt 前面） |
| 随机打乱 | 随机排序 |
| 反向排列 | 倒序 |

**选项：**
- 区分大小写：影响排序结果

**使用方法：**
1. 输入文本（每行一条）
2. 选择排序模式
3. 点击"排序"按钮

**应用场景：**
- 数据排序整理
- 名单排序
- 文件列表排序
- 日志分析排序

### 5. Markdown 转 HTML (Markdown to HTML)

**功能描述：**
将 Markdown 格式文本转换为 HTML 代码。

**支持的 Markdown 语法：**
- 标题（# ## ### 等）
- 粗体（**text**）和斜体（*text*）
- 列表（有序/无序）
- 链接和图片
- 代码块
- 引用块
- 表格（GFM）
- 删除线

**选项：**
- GitHub 风格 Markdown (GFM)：启用表格等扩展语法

**使用方法：**
1. 输入 Markdown 文本
2. 可选：开启 GFM 支持
3. 点击"转换为 HTML"
4. 查看结果和实时预览

**应用场景：**
- 博客文章转换
- 文档生成
- 邮件模板制作
- 静态网站生成

---

### 6. HTML 转 Markdown (HTML to Markdown)

**功能描述：**
将 HTML 代码转换为 Markdown 格式。

**支持的 HTML 标签：**
- 标题（h1-h6）
- 段落和换行
- 粗体和斜体
- 列表（ul/ol/li）
- 链接和图片
- 表格
- 代码块

**使用方法：**
1. 输入 HTML 代码
2. 点击"转换为 Markdown"
3. 复制转换结果

**应用场景：**
- 网页内容转 Markdown
- 邮件内容提取
- 文档格式转换
- 内容备份

## 数据转换工具

### 7. JSON 格式化 (JSON Format)

**功能描述：**
提供6种 JSON 处理操作。

**操作模式：**
| 操作 | 说明 |
|------|------|
| 格式化 | 美化 JSON，添加缩进 |
| 压缩 | 移除所有空格，最小化 JSON |
| 验证 | 检查 JSON 语法是否正确 |
| 排序键 | 按键名字母排序 |
| 转义 | 转义特殊字符用于字符串 |
| 反转义 | 反转义 JSON 字符串 |

**特点：**
- 自动修复常见 JSON 错误
- 可选择缩进空格数（2/4/6/8）
- 显示详细的错误位置

**使用方法：**
1. 输入 JSON 数据
2. 选择操作模式
3. （格式化/排序时可选择缩进）
4. 点击"处理"

**应用场景：**
- API 调试
- 配置文件格式化
- 数据验证
- 日志分析

**转换方向：**
- XML → JSON：解析 XML 并转换为 JSON

**XML 解析选项：**
| 选项 | 说明 |
|------|------|
| 始终使用数组 | 即使只有一个子元素也使用数组 |
| 去除空白 | 去除文本中的空白字符 |

**使用方法：**
1. 选择转换方向
2. 输入对应格式的数据
3. 配置解析选项（XML→JSON时）
4. 点击"转换"

**应用场景：**
- 数据格式迁移
- API 接口转换
- 配置文件转换
- 数据导入导出

### 12. 进制转换 (Binary Hex Convert)

**功能描述：**

**支持的进制：**
- 二进制 (BIN)
- 八进制 (OCT)
- 十进制 (DEC)
- 十六进制 (HEX)
- 三十二进制
- 三十六进制

**快捷转换：**
- BIN → DEC / BIN → HEX

**高级功能：**

**使用方法：**
1. 输入数字
2. 选择原进制
3. 选择目标进制
4. 点击"转换"

**应用场景：**
- 编程调试
- 颜色代码转换
- 权限计算
- 数据分析

## 开发者工具

### 13. UUID 生成器 (UUID Generator)

**功能描述：**
生成各种版本的 UUID（通用唯一标识符）。

**UUID 版本：**
| 版本 | 说明 | 特点 |
|------|------|------|
| v1 | 基于时间和 MAC 地址 | 有序、可追溯 |
| v3 | 基于 namespace 和名称的 MD5 | 相同输入生成相同 UUID |
| v4 | 随机生成 | 最常用、完全随机 |
| v5 | 基于 namespace 和名称的 SHA-1 | 相同输入生成相同 UUID |

**功能：**
- 批量生成（1-100个）
- UUID 验证
- 复制单个/全部

**v3/v5 参数：**
- Namespace：可选预定义命名空间（DNS/URL/OID/X.500）或自定义
- Name：用于生成 UUID 的名称字符串

**使用方法：**
1. 选择 UUID 版本
2. 设置生成数量
3. v3/v5 需要提供 namespace 和 name
4. 点击"生成"

**应用场景：**
- 数据库主键生成
- 分布式系统 ID
- 会话标识
- 文件唯一命名

---

### 14. Hash 生成器 (Hash Generator)

**功能描述：**
生成文本的各种哈希值。

**支持的算法：**
| 算法 | 输出长度 | 安全性 |
|------|----------|--------|
| MD5 | 128位 | 已不推荐用于安全用途 |
| SHA-1 | 160位 | 已不推荐用于安全用途 |
| SHA-256 | 256位 | 推荐 |
| SHA-384 | 384位 | 高安全性 |
| SHA-512 | 512位 | 最高安全性 |

**HMAC 支持：**
- 可选密钥认证
- 支持所有哈希算法

**输出格式：**
- 十六进制（默认）
- Base64
- Latin1

**使用方法：**
1. 输入文本
2. 选择算法或 HMAC
3. HMAC 需要提供密钥
4. 选择输出格式
5. 点击"生成哈希"

**应用场景：**
- 密码存储
- 文件校验
- 数字签名
- 数据完整性验证

### 15. 颜色转换器 (Color Converter)

**功能描述：**
解析、转换和操作颜色。

**支持的颜色格式：**
- HEX（#ff0000）
- RGB（rgb(255, 0, 0)）

3. **渐变生成**：生成中间过渡色
4. **颜色变体**：
   - 更亮/更暗
   - 灰度
   - 反色
   - 互补色

**使用方法：**
1. **解析颜色**：输入颜色值，点击"解析颜色"
2. **混合颜色**：选择两种颜色，调整比例，点击"混合"
3. **渐变生成**：选择两种颜色，点击"渐变"
4. **变体生成**：解析颜色后，点击"变体"

**应用场景：**
- UI 设计
- 主题开发

- CSS 样式编写

### 16. Crontab 解析器 (Crontab Parser)

**功能描述：**
解析和验证 Crontab 定时任务表达式。

**Crontab 格式：**
```
* * * * *
│ │ │ │ │
│ │ │ │ └─ 星期几 (0-6, 0=周日)
│ │ │ └─── 月份 (1-12)
│ │ └───── 日期 (1-31)
│ └─────── 小时 (0-23)
└───────── 分钟 (0-59)
```

**支持的特殊字符：**
- `*` ：任意值
- `*/n` ：每隔 n
- `n-m` ：范围
- `n,m` ：多个值

**6字段格式：**
支持包含秒字段的扩展格式

**功能：**
- 表达式验证
- 自然语言描述
- 计算下次执行时间

**常用示例：**
| 表达式 | 说明 |
|--------|------|
| `*/5 * * * *` | 每5分钟 |
| `0 * * * *` | 每小时 |
| `0 0 * * *` | 每天0点 |
| `0 0 * * 1` | 每周一 |
| `0 9-17 * * 1-5` | 工作时间每小时 |

**使用方法：**
1. 输入 Crontab 表达式
2. 点击"解析表达式"查看说明
3. 点击"计算执行时间"获取下次运行时间

**应用场景：**
- 定时任务配置
- 服务器调度设置
- 自动化脚本配置
- 定时备份设置

### 17. 时间戳转换 (Timestamp Convert)

**功能描述：**
时间戳与日期时间互相转换。

**支持的操作：**
1. **时间戳 → 日期**：将时间戳转换为可读日期
2. **日期 → 时间戳**：将日期转换为时间戳
3. **时间戳范围**：获取不同精度时间戳的范围

**时间戳单位：**
| 单位 | 位数 | 示例 |
|------|------|------|
| 秒 | 10位 | 1704000000 |
| 毫秒 | 13位 | 1704000000000 |
| 微秒 | 16位 | 1704000000000000 |

**时间戳范围：**
| 单位 | 最小值 | 最大值 |
|------|--------|--------|
| 秒 | -62135596800 | 253402300799 |
| 毫秒 | -62135596800000 | 253402300799999 |
| 微秒 | -62135596800000000 | 253402300799999999 |

**快捷输入：**
- "today"：今天0点
- "yesterday"：昨天0点
- "now"：当前时间戳

**时区支持：**
- 支持选择不同时区显示

**使用方法：**
1. **时间戳转日期**：输入时间戳，选择单位，点击"时间戳 → 日期"
2. **日期转时间戳**：输入日期字符串，点击"日期 → 时间戳"
3. **查看范围**：点击"获取时间戳范围"

**应用场景：**
- 日志时间分析
- API 调试
- 数据库查询
- 时间计算
