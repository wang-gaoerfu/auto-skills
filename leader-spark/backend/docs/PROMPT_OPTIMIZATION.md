# System Prompt 优化说明

## 优化目标

确保Agent严格遵循以下原则：
1. ✅ 必须基于知识库回答，不编造、不臆测
2. ✅ 必须先检索知识库，再组织回答
3. ✅ 无知识库内容时，明确提示"请选择人工服务"
4. ✅ 转人工提示清晰、直接、友好

---

## 核心改进点

### 1. 强制知识库检索流程

**之前：**
- 没有明确要求必须先检索
- 可能基于常识回答

**现在：**
```
第一步：强制知识库检索
对于用户的每个问题，必须按以下顺序操作：
1. 首先调用 `check_knowledge_relevance` 工具检查问题相关性
2. 根据检查结果决定后续操作
```

**改进效果：** 确保每个问题都先检查知识库相关性，不会漏检

---

### 2. 严格的相关性判断

**新增四级判断机制：**

| 相关性级别 | 评分范围 | 处理方式 |
|-----------|---------|---------|
| NO_MATCH | 无匹配 | ❌ 立即转人工，不搜索 |
| LOW_MATCH | < 0.5 | ❌ 立即转人工，不搜索 |
| MEDIUM_MATCH | 0.5 - 0.7 | ⚠️ 搜索后谨慎回答或转人工 |
| HIGH_MATCH | ≥ 0.7 | ✅ 搜索后正常回答 |

**改进效果：** 精确控制回答质量，避免低质量内容

---

### 3. 明确的转人工话术

**之前：**
```
建议您转接人工专家服务，获取更精准的解答。请问您需要我为您安排转接吗？
```

**现在：**
```
您好！关于您的问题，我查询了知识库但未找到相关信息。

这可能是因为：
- 该问题超出了我当前的知识库覆盖范围
- 您的问题需要更专业的个性化分析

**建议您选择人工服务**，我们的专业顾问可以为您提供更精准、更详细的解答。

请问您需要我为您转接人工服务吗？
```

**改进效果：**
- ✅ 更友好（"您好！"）
- ✅ 更清晰（明确说明原因）
- ✅ 更直接（"建议您选择人工服务"加粗）
- ✅ 更专业（使用"专业顾问"、"个性化分析"等词汇）

---

### 4. 严禁行为清单

**新增明确的禁止项：**

1. ❌ **不检索直接回答**：任何问题都必须先调用工具检索知识库
2. ❌ **编造答案**：不得根据常识、推理或外部知识编造答案
3. ❌ **强行回答**：没有知识库内容时，不得强行提供通用建议
4. ❌ **模糊来源**：必须明确说明内容来自知识库
5. ❌ **超出范围回答**：超出专业领域的问题必须转人工
6. ❌ **模糊转人工**：转人工提示必须明确、直接

**改进效果：** 给AI明确的边界，防止越界

---

### 5. 诚实原则强化

**新增特别说明：**

```
# 特别说明

1. **知识库的局限性**：你的知识库可能不完整，某些专业问题可能没有相关内容，这是正常的
2. **诚实是关键**：不知道就是不知道，不要试图"帮助"用户编造答案
3. **转人工是正确的选择**：转人工不是"失败"，而是为用户提供更好服务的方式
4. **用户理解**：用户会理解知识库的局限性，他们会更欣赏诚实的态度
```

**改进效果：** 让AI理解"诚实"比"全能"更重要

---

### 6. 标准回答格式

**新增统一的输出格式：**

**成功回答格式：**
```markdown
### 解答
【基于知识库内容的回答】

### 知识库来源
以上内容来自知识库检索结果：
- 【引用知识库中的关键内容片段】

### 延伸说明
【如果有知识库中的补充说明】

### 建议
【如果有知识库中的实践建议】

---
*本回答基于知识库内容，如需更深入的个性化咨询，建议选择人工服务。*
```

**转人工格式：**
```
您好！关于您的问题，我查询了知识库但未找到相关信息。

这可能是因为：
- 该问题超出了我当前的知识库覆盖范围
- 您的问题需要更专业的个性化分析

**建议您选择人工服务**，我们的专业顾问可以为您提供更精准、更详细的解答。

请问您需要我为您转接人工服务吗？
```

**改进效果：** 输出格式统一，用户阅读体验更好

---

### 7. 专业领域明确

**明确专业范围：**
```
你的专业范围包括：
- 领导力测评工具与方法
- 领导力发展模型
- 组织行为学
- 人才发展策略
- 情商领导力
- 变革管理
- 团队建设

**注意**：对于以上专业领域的问题，如果知识库中没有相关内容，也必须转人工。专业领域不等于"必须能回答"，是否有内容取决于知识库。
```

**改进效果：** 明确AI的角色边界

---

### 8. 完整示例

**新增3个示例：**

1. **成功回答示例**：知识库有内容时如何回答
2. **转人工示例**：知识库无内容时如何转人工
3. **超出领域示例**：超出专业范围时如何转人工

**改进效果：** 给AI具体的参考案例

## 使用建议

### 1. 导入知识库内容

为了让Agent能回答更多问题，请导入相关书籍内容：

```bash
python scripts/import_word.py assets/你的书籍.docx
```

### 2. 调整相关性阈值

如果发现转人工太频繁，可以调整工具中的阈值：

**修改 `src/tools/knowledge_search_tool.py`：**
```python
# 当前阈值
HIGH_MATCH: score >= 0.7
MEDIUM_MATCH: 0.5 <= score < 0.7
LOW_MATCH: score < 0.5

# 如需调整（示例）
HIGH_MATCH: score >= 0.6  # 降低到0.6
MEDIUM_MATCH: 0.4 <= score < 0.6
LOW_MATCH: score < 0.4
```

### 3. 定期审查转人工日志

建议定期查看转人工的问题，分析原因：
- 如果是知识库内容不足 → 补充导入相关内容
- 如果是问题表达不清 → 优化转人工话术，引导用户补充信息
- 如果是超出范围 → 确认转人工逻辑正常

## 总结

通过本次优化，Agent现在：

✅ **严格遵循知识库**：所有回答必须来自知识库检索结果
✅ **智能边界控制**：四级相关性判断，精确控制回答质量
✅ **明确转人工**：清晰的转人工话术，友好提示用户
✅ **诚实专业**：不知道就不知道，不编造不臆测
✅ **标准化输出**：统一的回答格式，提升用户体验

**核心改进**：从"尽力回答"转变为"有据可依、无据不答"，更加专业、可靠！
