### 2. 优化转人工话术

**修改文件**：`config/agent_llm_config.json`

**旧话术**：
```
您好！关于您的问题，我查询了知识库但未找到相关信息。

这可能是因为：
- 该问题超出了我当前的知识库覆盖范围
- 您的问题需要更专业的个性化分析

**建议您选择人工服务**，我们的专业顾问可以为您提供更精准、更详细的解答。

请问您需要我为您转接人工服务吗？
```

**新话术（带主题提取）**：
```
您好！关于您提到的「{问题主题}」的问题，我查询了知识库但暂时没有找到相关的专业内容。

这个问题可能需要：
- 更深入的专业知识分析
- 结合您的具体情况进行个性化指导

**建议您选择人工服务**，我们的专业顾问可以为您提供关于「{问题主题}」的更精准解答。

请问您需要我为您转接人工服务吗？
```

**关键改进**：
- ✅ 提取并显示用户提问的主题（如「AI技术提升团队效率」）
- ✅ 语气更友好（"暂时没有找到" vs "未找到"）
- ✅ 更具体的说明（需要什么）
- ✅ 双重提及问题主题（让用户感受到被理解）

**主题提取示例**：
| 用户问题 | 提取的主题 |
|---------|-----------|
| 什么是360度评估？ | 360度评估 |
| 如何使用AI技术提升团队效率？ | AI技术提升团队效率 |
| Python编程语言有什么特点？ | Python编程语言特点 |
| 客户说"我总是失败"怎么办？ | 提升客户信心 |

| 阈值类型 | 分值范围 | 说明 |
|---------|---------|------|
| LOW_MATCH | < 0.3 | 低匹配，转人工 |
| MEDIUM_MATCH | 0.3 - 0.5 | 中等匹配，检索后判断 |
| HIGH_MATCH | ≥ 0.5 | 高匹配，基于知识库回答 |

### 注意事项
- 当前阈值设置为临时方案（0.3），适合当前知识库内容
- 如果导入更多内容，可考虑恢复到原始设置（0.5）
